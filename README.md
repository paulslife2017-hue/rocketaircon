# 로켓에어컨

에어컨 수리·냉매 점검·누수·소음·실외기 문제를 안내하는 로켓에어컨 랜딩 페이지입니다.

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드 확인:

```bash
npm run build
```

## 주요 구성

- 오늘 바로 출장을 강조한 메인 화면
- 냉방 불량, 작동 불가, 실외기 불량 등 6개 서비스 안내
- 실제 현장 작업 사진
- 출장 절차와 자주 묻는 질문
- 모바일 반응형 상담 화면

## 기술 구성

- React 19
- Next.js/Vinext
- TypeScript
- Vite
